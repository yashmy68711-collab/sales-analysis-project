# Sales Analysis Project

A Python-based Sales Data Analysis project that uses **Pandas** and **NumPy** to clean, process, and analyze sales data stored in a CSV file.

The project demonstrates the basic workflow of a data analysis application, starting from raw sales data and performing data cleaning, transformation, aggregation, and statistical calculations to generate useful business insights.

---

## 📌 Project Overview

The purpose of this project is to analyze a dataset containing sales transactions.

The program reads sales information from a CSV file and performs several operations such as:

- Loading sales data using Pandas
- Cleaning missing and duplicate data
- Converting dates into a proper datetime format
- Calculating total sales/revenue
- Extracting the month from transaction dates
- Generating monthly sales reports
- Identifying the top-performing products
- Identifying the highest-value customers
- Performing numerical calculations using NumPy

This project is designed as a beginner-friendly introduction to **Data Analysis with Python**.

---

## 🛠️ Technologies Used

### Python

The main programming language used to develop the project.

### Pandas

Pandas is used for:

- Reading CSV files
- Creating and manipulating DataFrames
- Cleaning the dataset
- Removing missing values
- Removing duplicate records
- Converting date columns
- Grouping and aggregating sales data

### NumPy

NumPy is used for numerical calculations such as:

- Total revenue
- Average revenue
- Highest sale
- Lowest sale
- Converting sales data into NumPy arrays
